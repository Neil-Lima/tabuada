## 📋 Sobre o Projeto

Desenvolvi esta Tabuada Interativa como uma aplicação web moderna que facilita o aprendizado e prática de operações matemáticas. Construída com Next.js, TypeScript e Redux, ela oferece uma experiência dinâmica e intuitiva para estudantes, professores e qualquer pessoa que precise praticar cálculos básicos.

### ✨ Recursos Principais

- **Múltiplas Operações**: Multiplicação, divisão, adição e subtração
- **Intervalos Personalizáveis**: Defina onde a tabuada começa e termina
- **Visualização Rápida**: Resultados exibidos de forma clara e organizada
- **Tema Claro/Escuro**: Alternância entre temas para melhor conforto visual
- **Layout Responsivo**: Funciona perfeitamente em dispositivos móveis e desktop
- **Controles Intuitivos**: Interface fácil de usar com botões de ação claros
- **Feedback Visual**: Destaque para resultados e operações

## 🔧 Instalação e Configuração

```bash
# Clone o repositório
git clone https://github.com/Neil-Lima/tabuada.git
cd tabuada

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`

## 🧮 Como Usar

1. Selecione a operação matemática desejada (multiplicação, divisão, adição ou subtração)
2. Digite o número base para a tabuada
3. Defina o intervalo desejado (onde começa e onde termina)
4. Clique em "Calcular" para ver os resultados
5. Use o botão "Limpar" para reiniciar os campos
